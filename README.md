# Travel ML & MLOps Capstone

An end-to-end Machine Learning and MLOps project built using travel
booking data.

## Project Overview

This project develops and deploys three machine learning components:

1. Flight Price Prediction
2. Gender Classification
3. Hotel Recommendation

The project demonstrates the complete ML lifecycle:

Data → EDA → Preprocessing → Model Training → Evaluation
→ MLflow → API → Testing → Docker → Kubernetes → Airflow → Jenkins → Streamlit
